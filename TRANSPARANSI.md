# Transparansi Dana — Santri Admin Gratis

> Single source of truth dana proyek ini. Laporan diperbarui **1x sebulan, maks tanggal 5**.
> Dana **hanya** untuk server/hosting/domain. Setiap baris keluar wajib bukti di `docs/bukti/YYYY-MM/`.
> Pengeluaran > Rp100rb langsung dicatat (tidak menunggu akhir bulan). Bulan kosong tetap ditulis.

## Status donasi

- **Fase 1 (saat ini): donasi BELUM dibuka** — app masih dibangun, target 20+ pengguna aktif dulu.
- Channel saat dibuka: utama **Trakteer + QRIS**, sekunder GitHub Sponsors (setelah verifikasi payout Indonesia).

## Catatan

- Saldo harus klop: `saldo = total masuk - total keluar`.
- Target server bulanan saat ini: **Rp0/bln** (0–100 pengguna, full free-tier).
- Batas realistis 1.000 pengguna: **maks Rp80–250rb/bln**.
- Aturan upgrade: **jangan sewa VPS sebelum donasi rutin > Rp500rb/bln selama 3 bulan**.
